# Idea Board

## Presentation Topics

- Topic: Spec-Driven Development (SDD)
- Audience: Experienced developers who already use AI tools but lack structure
- Duration: 20 minutes

## Key Messages

1. Your AI doesn't know what you want — and neither do you, until you write it down
2. Specifications are executable contracts, not documentation after the fact
3. SDD turns vague intent into machine-verifiable behavior

## Structure

- Opening — hook: the gap between intent and output
- The problem — context window gambling
- What is SDD — the framework
- How it works — spec → generate → verify
- Closing + Q&A
